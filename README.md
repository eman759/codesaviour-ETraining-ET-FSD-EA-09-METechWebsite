ME Technologies Website

Project Overview

This project is a website for ME Technologies, an engineering services and technology company.

Technology Stack

- Frontend: React and Tailwind CSS
- Backend: Node.js and Express.js
- Code Quality: ESLint
- Version Control: Git and GitHub
